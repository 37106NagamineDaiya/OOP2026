# WPF 天気予報アプリ

Visual Studio 2022 / C# / .NET 8 / WPF で動作する天気予報アプリです。Open-Meteo APIから実データを取得します。

## 作成した機能
- 現在の気温、天気、湿度、風速を表示
- 7日間の天気、最高・最低気温、最大降水確率を表示
- 東京、札幌、仙台、前橋、名古屋、大阪、広島、福岡、那覇を選択可能
- 更新ボタンおよび地域変更時にAPIを再取得
- 通信失敗、タイムアウト、データ不正を画面下部に表示し、アプリを強制終了させない
- 画面処理、通信・JSON解析、データモデルを別クラスに分離
- NuGet追加パッケージなし（HttpClient / async-await / System.Text.Jsonを使用）

## 実行手順
1. Visual Studio 2022で `WeatherForecastApp.csproj` を開く
2. .NET 8 SDKと「.NET デスクトップ開発」ワークロードが未導入ならVisual Studio Installerで追加する
3. ビルドして実行する
4. インターネット接続を許可し、地域を選ぶか「更新」を押す
