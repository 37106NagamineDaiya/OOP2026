# WeatherApp
Visual Studio 2022 / C# / .NET 8 / WPF用の天気予報アプリです。Open-Meteo APIから現在の気温・天気・湿度・風速と7日間の天気・最高最低気温・降水確率を取得します。地域変更、更新、通信エラー表示に対応し、画面・通信・データクラスを分離しています。NuGet追加パッケージは不要です。

## 実行
Visual Studio 2022で `WeatherApp.csproj` を開き、.NET 8と「.NETデスクトップ開発」を使用してビルド・実行してください。

## 指定コミット
- ★01 WPF プロジェクト作成
- ★02 天気 API からデータを取得
- ★03 天気予報の画面表示を完成
- ★04 動作確認と最終調整
